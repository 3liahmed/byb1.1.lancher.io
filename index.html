Get started in four steps

The first launch takes a few minutes because it downloads everything it needs.

  1. Download and open b.exeIf Windows shows a SmartScreen warning, choose More info, then Run anyway.
  2. Type a username3–16 letters, numbers or underscores. Keep the same name to keep your items on a server.
  3. Press Quick startIt makes a Fabric instance with the BYB Starter Pack and picks the best Minecraft version for it.
  4. Press PlayJava, game files and mods download by themselves. Then Minecraft opens.

Play on the BYB server

Press “Play BYB Server” in the launcher to join in one click, or copy the address.

Good to know

BYB Launcher uses offline accounts, so it works for singleplayer and servers with online-mode=false. It does not replace a Minecraft purchase: you need to own Minecraft: Java Edition. Mods and modpacks come from Modrinth, with no account or key.
